# MonkyBot avatar

`monky-logo.png` is the official Monky logo, copied unchanged from
[`MonkyOrg/Monky`, `images/Logo.png`](https://github.com/MonkyOrg/Monky/blob/main/images/Logo.png).
The artwork belongs to the Monky project; this official reference bot uses it
for its profile in both manual and marketplace modes.

The image is bundled in the installable package. No remote image request is
needed to display the bot avatar.
